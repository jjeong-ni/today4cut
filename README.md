# TODAY 4 CUT

모바일과 데스크톱 브라우저에서 동작하는 정적 4컷 포토부스입니다. 서비스명은 `TODAY 4 CUT`입니다.

## 기능

- 비회원 촬영, 다운로드, 공유
- 촬영 전 3가지 컷 구성 선택: 세로 4컷, 2 x 2, 큰컷 + 3컷
- 선택한 구성대로 한 화면에 4개 프레임을 보여주고 순서대로 촬영
- 회원가입, 로그인, 로그아웃
- 로그인 사용자의 4컷 사진 자동 보관함 저장
- 다음 접속 시 같은 브라우저에서 보관함 확인, 다운로드, 삭제
- Android, iOS, 데스크톱 화면 크기에 맞춘 반응형 레이아웃
- GitHub Pages에 바로 올릴 수 있는 순수 HTML/CSS/JS 구조

## 저장 방식

이 버전은 서버 없이 동작합니다. 회원 정보와 사진 보관함은 현재 기기의 브라우저 저장소에만 남습니다.
다른 기기에서 같은 계정으로 접속하거나 서버에 백업하려면 별도 백엔드와 데이터베이스가 필요합니다.

## 실행

카메라 권한 때문에 `file://`보다 `localhost` 또는 HTTPS에서 여는 편이 안정적입니다.

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

그 다음 브라우저에서 `http://127.0.0.1:4173`을 열면 됩니다.

카메라가 열리지 않으면 주소창 왼쪽 권한 아이콘에서 카메라를 허용한 뒤 앱의 `권한 다시 요청` 버튼을 누르세요.

## 파일

- `index.html`: 화면 구조, 계정 모달, 보관함 화면, 메타 태그
- `styles.css`: 반응형 포토부스 UI
- `app.js`: 카메라, 필터, 촬영, 계정, 보관함 저장 로직
